# CBSE Class 12th PYQ Portal (2023–2026)
### *Curated & Mentored by NISHANT MISHRA*

A modern, responsive, and interactive educational web application providing previous year question papers, step-by-step solutions, official CBSE marking schemes, and examiner tips for CBSE Class 12 students.

---

## 📚 Subjects Covered

1. **Mathematics (Sub Code: 041)**
   - Calculus, Vectors & 3D Geometry, Matrices & Determinants, Probability, Linear Programming
2. **Physics (Sub Code: 042)**
   - Electrostatics, Current Electricity, Ray Optics, Modern Physics, EMI & AC, Semiconductors
3. **Chemistry (Sub Code: 043)**
   - Solutions, Electrochemistry, Chemical Kinetics, Coordination Compounds, Organic Chemistry Reactions
4. **Computer Science (Sub Code: 083)**
   - Python Programming, File Handling (Binary & Text), Stacks Data Structure, SQL Queries & Networks
5. **English Core (Sub Code: 301)**
   - Advanced Writing (Notice, Letter to Editor, Reports) and Literature (Flamingo & Vistas)

---

## 🌟 Key Features

- **Years 2023 to 2026**: Includes official CBSE Board question papers, model papers, and 2026 sample papers.
- **Official Step-Wise Marking Schemes**: Point-by-point allocation (+0.5, +1, +2 marks) so students know how evaluators grade answers.
- **Examiner's Tips & Traps**: Practical warnings on common pitfalls that cause mark deductions.
- **KaTeX LaTeX Math Rendering**: Beautiful rendering of calculus, vectors, matrices, and chemical equations.
- **Syntax Highlighting for CS**: Python code and SQL queries formatted with Prism.js.
- **Interactive Self-Test Mode**: Hide answers to practice solving questions independently.
- **Formula & Revision Vault**: One-click quick revision cards for high-yield formulas and concepts.
- **One-Click Save to PDF / Print**: Clean `@media print` layout to print or save question papers offline.
- **Dark & Light Mode**: Seamless theme toggle for day and late-night study sessions.
- **Offline & Zero-Dependency Ready**: Open `index.html` directly in any web browser without needing any installation.

## 🚀 How to Run the Website

### Option 1: Direct Browser Launch (Easiest)
Simply double-click on `index.html` or right-click `index.html` &rarr; Open with (Google Chrome / Microsoft Edge / Firefox).

### Option 2: Local Python Web Server
If you want to run a local server:
```powershell
cd C:\Users\nisha\.gemini\antigravity\scratch\cbse-class12-pyq
py -m http.server 8000
```
Then open your browser and visit: `http://localhost:8000`
